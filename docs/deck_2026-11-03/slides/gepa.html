GEPA prompt optimisation: three tries, no gain

Ask 4 from the last meeting. Automatic rewriting of the zero-shot frontier prompt, DSPy and GEPA, both prompt versions, five folds each. About 60 dollars in total.

  • Scored on per-row squared error, it made the prompt worse on every target. Validation rose in all ten runs; held-out entropy fell 0.296 to 0.139 and remaining length 0.411 to 0.105.
  • The cause is measured, not guessed. The rewritten prompts paste in each target's training median and range, so predictions gain the scale and lose the ordering. Within-cut correlation fell 0.55 to 0.42 on entropy.
  • Two retries with ranking-based scores were stopped by a rule fixed before seeing data. With a pure ranking score, validation moved by 0.000 to 0.008, and four of seven finished runs simply kept the original prompt.
  • Same mechanism as "examples hurt". Our comparison is calibrated, so the scale is free and only the ranking damage counts. The original zero-shot prompt is still the best in-context prompt we have.

Next, and it costs nothing: rerun with a local model on the full dataset to find a working setup before paying again.

Setup, if he asks. The prompt optimised is the zero-shot GPT-6 Luna prompt, the best in-context config at 0.294 calibrated entropy against our probe's 0.309 on the same rows. Luna was both the task model and the reflection model. Per outer fold GEPA saw only the other folds' questions, split 70/30 by question, and was tested on the same rows the probe was scored on. The seed prompt rerun through DSPy reproduces the old Luna run, 0.296 against 0.294, which validates the harness. Try 1 cost 28 dollars and all ten runs completed. The stopping rule, fixed before any data was seen: stop if in two or more folds a candidate beats the seed on validation while its within-cut rank correlation on entropy or remaining length drops more than 0.05. It triggered both times. Try 2 used within-cut percentiles and still rewarded shrinking toward the middle, the winning prompt narrowed its entropy spread from 31 to 24 percentile points. Try 3 scored each batch by mean Spearman over the four targets, which is invariant to any monotone rescaling, so neither scale nor shrinkage could earn score; there the consistent pattern was that new prompts ranked remaining length better and entropy worse. The learned prompts ran 430 to 735 words against the seed's 196. Three conclusions Rish draws: any future run must use a scale-free ranking-only score; with such a score GEPA finds no prompt that ranks better overall; and this is consistent with the difficulty finding, since an instruction rewrite cannot add information the question text does not carry.
