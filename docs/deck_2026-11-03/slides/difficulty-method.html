Isolating question difficulty as a confounder

The worry. Both our probe and the frontier model might only be reading how hard the question is. If so, nothing here is about the reasoning chain.

The test. Regress a quadratic in a per-question difficulty measure out of both the target and the prediction, then rescore. Refitted inside each of 2,000 question bootstrap draws, so the intervals account for it.

  • Measure 1, label-derived: computed from the same rollouts as the target, so it is partly circular and removes too much. This number understates what the probe retains.
  • Measure 2, question-text-derived: an out-of-fold prediction from the question words only, so it is non-circular, but it captures only about a quarter of real difficulty and removes too little. This number overstates it.

Two controls that fail in opposite directions. Read the range, not either number.

Neither measure alone is defensible, which is why both are run. The label-derived one on GPQA and MMLU-Pro is p_gold, the fraction of that question's rollouts that are correct. GlobalOpinionQA has no gold answer, so its label-derived measure is the 0 percent cut normalised entropy instead, which makes its over-removal unusually severe because that quantity is close to the target itself. Deliberately NOT calling these bounds: that would assume the text measure removes a subset of what true difficulty removes, and it may also be removing topic, option count or question length, so the two are not nested. The honest claim is the direction of the bias, not a bound. The text measure correlates 0.507 with the real pass rate on GPQA and 0.476 on MMLU-Pro, so it captures about a quarter of difficulty's variance. The weak link is that our non-circular control is a bag of words; a frontier model rating difficulty would be far sharper and costs about 3 dollars, and we would like to run it. One scope limit: commitment was NOT partialled, because the residual of a binary target is not a probability, so this covers four of the five targets.
