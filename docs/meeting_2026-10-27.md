# Questions to ask — detail

Short versions for the slide are above. Longer framing for the conversation:

## 1. Black-box monitor — other representations

*"You asked for the black-box monitor with different representations. We've only fed it the full
prefix text. Which of these do you want?"*

- **Question only, no chain.** Direct test of whether the signal is just question difficulty.
  Ties into slide 10. **My recommendation — cheapest and most informative.**
- **Last N sentences of the chain.** We now have this code (the smaller-prompt run). Tests
  whether the recent reasoning carries it.
- **Trivial scalars only** — prefix length, sentence count, position. The floor.
- **Something numeric from the activations** — e.g. top principal components as text. Possible
  but we think it's unlikely to read well as a prompt.

Cost: each is roughly 1–2 GPU-hours on Gemma, or ~$5 on GPT-6 Luna.

## 2. GEPA prompt optimization

*"You described varying the prompt from training samples, picking an optimal example set, then
testing. Two parts — which do you mean?"*

- **Instruction optimization** — rewrite the task description automatically against a held-out
  score.
- **Example selection** — choose *which* k examples go in the prompt, rather than our current
  round-robin over questions and cut points.

Worth raising: **our k-curve bears on this already.** More examples make it strictly worse — k=0
beats k=10 and k=50, for both GPT-6 and Gemma. So example selection is optimizing a knob that
currently points to "use none". Ask whether he expects selection to reverse that, or whether
instruction optimization is the real target.

Also needs settling: **what we'd measure.** Optimizing prompts against our fold structure risks
fitting the test set unless we hold out a further split.

## 3. The question-difficulty finding

*"We can predict which questions produce uncertain rollouts. We cannot predict which chain of a
given question will. Does that change what the paper claims?"*

- It does not change any published number
- It changes the sentence the paper is built around
- Downstream: whether we collect more questions (allocation result points that way)
- The 0% checkpoint experiment would measure the difficulty floor directly — ready to run,
  a few CPU-hours
